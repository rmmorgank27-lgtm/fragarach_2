# Fragarach II v1.0a

**Status:** Stable operational baseline
**Released:** 2026-07-13

Fragarach II v1.0a is the first trusted recovery baseline for the native historical market-data authority.

## Stable capabilities

- canonical instrument registry and immutable authority model;
- Twelve Data acquisition with Yahoo fallback and provider identity resolution;
- registration, retirement, reactivation, and permanent-removal lifecycle;
- immutable evidence ingestion, row-level quarantine, validation, and Truth Engine;
- Estate Truth with Estate → Market → Subgroup → Symbol navigation;
- versioned SPEC-018 external consumer contract and Morphix FCv1 integration;
- signed native Operations Console workflows.

## Permanent acceptance rule

> A feature is not accepted until the operator can successfully execute the complete workflow from the signed native application. Backend implementation alone is insufficient.

Future work is incremental and compatibility-preserving unless an explicit architectural specification authorizes a breaking change.
